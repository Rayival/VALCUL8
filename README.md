VΛLCUL8 - Web-Based Scientific Calculator

VΛLCUL8 adalah aplikasi web kalkulator ilmiah yang interaktif dan responsif, dibangun menggunakan React dan Tailwind CSS. Desain antarmuka aplikasi ini terinspirasi dari model kalkulator fisik klasik (KK-82MS), memberikan pengalaman penggunaan yang realistis dan familier langsung dari browser Anda.

✨ Fitur Utama

Operasi Matematika Lengkap: Mendukung operasi dasar (tambah, kurang, kali, bagi) serta fungsi ilmiah lanjutan seperti trigonometri (sin, cos, tan), logaritma, eksponensial, akar, dan pangkat.

Tema Ganda (Dual Themes):

🌸 Pink Theme: Tampilan cerah dan estetik yang terinspirasi dari perangkat fisik.

🌌 Navy Theme: Tampilan gelap (dark mode) yang elegan dan nyaman di mata.

Desain Realistis: Tata letak tombol (termasuk tombol D-pad Replay, Shift, Alpha) dan layar LCD digital didesain agar menyerupai kalkulator fisik.

Desain Responsif: Dapat digunakan dengan nyaman baik melalui perangkat desktop (PC/Laptop) maupun mobile (Smartphone/Tablet).

🚀 Teknologi yang Digunakan

Proyek ini dibuat dengan tumpukan teknologi modern:

React 18: Library JavaScript untuk membangun antarmuka pengguna (UI).

Vite: Build tool generasi baru yang super cepat.

Tailwind CSS v3: Framework CSS utility-first untuk proses styling yang cepat dan kustomisasi tanpa batas.

ESLint: Alat analisis kode untuk menjaga standar kualitas kode.

🛠️ Panduan Instalasi dan Penggunaan Lokal

Ikuti langkah-langkah di bawah ini untuk menjalankan proyek ini di komputer lokal Anda:

1. Persyaratan (Prerequisites)

Pastikan Anda sudah menginstal Node.js di komputer Anda. Anda bisa mengeceknya dengan menjalankan perintah node -v dan npm -v di terminal.

2. Kloning Repositori (Opsional)

Jika Anda menggunakan Git, kloning repositori ini. Jika tidak, cukup ekstrak folder proyek yang sudah Anda buat sebelumnya.

git clone https://github.com/username-anda/valcul8-app.git


3. Masuk ke Direktori Proyek

cd valcul8-app


4. Instal Dependensi

Jalankan perintah berikut untuk menginstal semua paket dan library yang dibutuhkan (React, Tailwind, dll):

npm install


5. Jalankan Server Pengembangan (Development Server)

Jalankan aplikasi di mode pengembangan:

npm run dev


Buka browser Anda dan kunjungi URL lokal yang tertera di terminal (biasanya http://localhost:5173/) untuk melihat aplikasi secara langsung.

📦 Membangun untuk Produksi (Build)

Jika Anda ingin mengunggah (deploy) aplikasi ini ke platform seperti Vercel, Netlify, atau GitHub Pages, jalankan perintah build:

npm run build


Perintah ini akan membuat folder dist yang berisi file HTML, CSS, dan JavaScript yang sudah dioptimalkan untuk production. Anda juga dapat menguji hasil build dengan menjalankan:

npm run preview
